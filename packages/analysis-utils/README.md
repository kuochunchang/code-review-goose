# @code-review-goose/analysis-utils

Shared utility functions for code analysis.

## Overview

Provides utility functions for Mermaid diagram validation, AST manipulation, and other common analysis tasks.

## Installation

```bash
npm install @code-review-goose/analysis-utils
```

## Features

- Mermaid diagram validation and auto-fixing
- AST helper functions
- Common code analysis utilities
