# Changelog

All notable changes to the "Goose Code Review" extension will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial release of Goose Code Review VS Code extension
- Class diagram generation for TypeScript/JavaScript files
- Sequence diagram generation for function call flows
- Flowchart generation for control flow analysis
- Interactive webview panel with Mermaid.js rendering
- Context menu integration for quick access
- Configurable analysis depth (1-5 levels)
- Analysis mode selection (focused vs comprehensive)
- Private member visibility toggle
- Auto-refresh capability
- Export diagrams as SVG
- Copy Mermaid code to clipboard

### Features
- Command Palette integration
- Right-click context menu commands
- VS Code theme-aware diagram rendering
- Workspace-scoped analysis
- Security: All analysis happens locally
- Privacy: No telemetry or data collection
